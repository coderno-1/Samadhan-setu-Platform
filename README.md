# Samadhan Setu · SIH26043

Citizen-to-solution collaboration platform that routes verified civic problems to universities, faculty, industry partners, and government administrators.

## Phase 1 included

- Responsive React + Tailwind public site
- Role-aware registration, login, and protected dashboards
- Express, MongoDB, JWT, and password-hashing authentication API
- Dashboard foundation for citizen, university, faculty, industry, and admin roles

## Run locally

1. Copy `.env.example` to `server/.env` and set `MONGODB_URI` and `JWT_SECRET`.
2. Run `pnpm install`.
3. Run `pnpm dev`.
4. Open `http://localhost:5173`.

The API runs on `http://localhost:5000`.
